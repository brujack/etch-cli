# Action Catalog

Full reference for all 38 manifest actions. Actions map to `lib/src/actions/<name>/`.

**Auditing action names:** YAML action names come from `#[serde(rename = "...")]` in `lib/src/actions/mod.rs` — not from Rust struct names. Struct names and YAML names diverge (e.g. struct `GroupAdd` → YAML `group.add`).

## Template Context Variables

Template engine is [Tera](https://keats.github.io/tera/). Available context variables: `user.username`, `user.home_dir`, `user.name`, `os.hostname`, `os.name`, `os.family`, `os.arch`, `os.distribution`, `manifest_dir`.

**Gotcha:** bare `{{ my_var }}` silently renders empty — always prefix with the namespace (e.g. `{{ variables.my_var }}`).
