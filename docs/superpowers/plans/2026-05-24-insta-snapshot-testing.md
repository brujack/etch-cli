# Snapshot Testing (`insta`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lock etch's user-visible CLI output (help text, version, dry-run messages) so accidental format changes fail CI rather than shipping silently.

**Architecture:** Add `insta` as a dev-dependency. Create a new integration test file `app/tests/snapshots.rs` with five snapshot tests. Commit the generated `.snap` baseline files alongside the tests. CI uses normal `cargo test` — no CI changes needed. Intentional output changes require `cargo insta review` + committed snapshot update.

**Tech Stack:** `insta` v1 (Rust snapshot testing), `cargo-insta` CLI (review tool), `assert_cmd`, `tempfile` (already present).

- [ ] **Step 3: Create `app/tests/snapshots.rs` with static tests**

Create the file with these three tests. The `filters()` helper applies VERSION and TMPDIR scrubbing to all tests consistently:

```rust
use assert_cmd::Command;

fn etch() -> Command {
    Command::cargo_bin("etch").unwrap()
}

fn filters() -> Vec<(&'static str, &'static str)> {
    vec![
        (r"\d+\.\d+\.\d+", "[VERSION]"),
        (r"/(?:private/)?(?:var/folders|tmp)/\S+", "[TMPDIR]"),
    ]
}

#[test]
fn help() {
    let output = etch().arg("-h").output().unwrap();
    insta::with_settings!({
        filters => filters()
    }, {
        insta::assert_snapshot!(String::from_utf8_lossy(&output.stdout));
    });
}

#[test]
fn apply_help() {
    let output = etch().args(["apply", "--help"]).output().unwrap();
    insta::with_settings!({
        filters => filters()
    }, {
        insta::assert_snapshot!(String::from_utf8_lossy(&output.stdout));
    });
}

#[test]
fn version() {
    let output = etch().arg("version").output().unwrap();
    insta::with_settings!({
        filters => filters()
    }, {
        insta::assert_snapshot!(String::from_utf8_lossy(&output.stdout));
    });
}
```

### Task 2: Add dry-run snapshot tests

**Files:**

- [ ] **Step 1: Add dry-run tests to `app/tests/snapshots.rs`**

Add these two tests to the bottom of the existing file. They create a minimal manifest (one `directory.create` action) in a tempdir, run dry-apply, and snapshot stdout:

```rust
use std::fs;
use tempfile::tempdir;

#[test]
fn dry_run() {
    let dir = tempdir().unwrap();
    fs::write(
        dir.path().join("test.yaml"),
        "actions:\n  - action: directory.create\n    path: somedir\n",
    )
    .unwrap();

    let output = etch()
        .current_dir(dir.path())
        .args(["--no-color", "-d", ".", "apply", "--dry-run"])
        .output()
        .unwrap();

    insta::with_settings!({
        filters => filters()
    }, {
        insta::assert_snapshot!(String::from_utf8_lossy(&output.stdout));
    });
}

#[test]
fn dry_run_verbose() {
    let dir = tempdir().unwrap();
    fs::write(
        dir.path().join("test.yaml"),
        "actions:\n  - action: directory.create\n    path: somedir\n",
    )
    .unwrap();

    let output = etch()
        .current_dir(dir.path())
        .args(["--no-color", "-v", "-d", ".", "apply", "--dry-run"])
        .output()
        .unwrap();

    insta::with_settings!({
        filters => filters()
    }, {
        insta::assert_snapshot!(String::from_utf8_lossy(&output.stdout));
    });
}
```

Note: `use std::fs;` and `use tempfile::tempdir;` must be added at the top of `snapshots.rs` if not already present.

- [ ] **Step 3: Inspect the dry-run snapshots**

```bash
cat app/tests/snapshots/snapshots__dry_run.snap
cat app/tests/snapshots/snapshots__dry_run_verbose.snap
```

Verify they contain the expected dry-run output:

- `snapshots__dry_run.snap` should contain `[dry run] no changes will be made` and `1 step(s) would run`
- `snapshots__dry_run_verbose.snap` should contain those plus `  would:` lines
- Neither should contain any raw tmpdir path (all replaced with `[TMPDIR]`)

If any raw path appears, it means the TMPDIR filter pattern doesn't match that OS's temp path format. In that case, update the filter pattern in `filters()`:

- macOS temp paths: `/var/folders/...` or `/private/var/folders/...`
- Linux temp paths: `/tmp/...`

Current pattern `r"/(?:private/)?(?:var/folders|tmp)/\S+"` covers both. If a path still appears, broaden to `r"(?:/private)?/(?:var|tmp)/\S+"`.
