# Dry-Run Mode Output Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `etch apply --dry-run` print a banner, per-action step counts, and (with `-v`) atom-level descriptions instead of silently skipping execution.

**Architecture:** Three surgical edits to `app/src/commands/apply.rs` — a banner after `let dry_run`, a step counter in the step loop, and a conditional summary line. The existing `--dry-run` flag and skip-execute guard are already in place; this adds output only. No trait or lib changes.

**Tech Stack:** Rust, clap, tracing, assert_cmd (integration tests), predicates

                            Ok(_) => (),

This test verifies that dry-run does not emit `step(s) would run` when every action is already in the desired state (the step filter drops all atoms because `should_run` is false). No implementation changes are required.

- [ ] **Step 1: Write the test**

Add to `app/tests/basic_usage.rs`:

```rust
#[test]
fn dry_run_nothing_to_do() {
    let t = TempDir::new().expect("could not create tempdir");
    let path = t.keep();

    // Pre-create the directory the manifest will try to create.
    // directory.create resolves path relative to CWD (= path), so
    // path/existing_dir must exist before etch runs.
    std::fs::create_dir(path.join("existing_dir"))
        .expect("could not create existing_dir");

    dir(
        "directory",
        vec![dir(
            "create",
            vec![f(
                "main.yaml",
                r#"
actions:
  - action: directory.create
    path: existing_dir
"#,
            )],
        )],
    )
    .create_in(&path)
    .expect("should have created test directories");

    cd(path).run("--no-color -d ./directory apply -m create --dry-run")
        .success()
        .stdout(predicates::str::contains("step(s) would run").not());
}
```

- [ ] **Step 2: Run the test and confirm it passes without any implementation changes**

```bash
cargo test -p etch-cli dry_run_nothing_to_do -- --nocapture
```

Expected: PASS — `existing_dir` already exists, `atom.plan()` returns `should_run: false`, the step filter removes it, and no `step(s) would run` line is printed.
