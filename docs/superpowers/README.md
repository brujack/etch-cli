Same under zip 2 and zip 9 (bug-scan, 2026-10-17). Write to a temp file in the same directory and rename on success. |

No Make target or CI job regenerates it or checks it is current, so editor autocomplete built on it is silently wrong. Fix: regenerate it, add a CI check that fails when `cargo run -p jsonschemagen` output differs from the committed file, and attach it to each release. A versioned schema also lets etch-config vendor a pinned action-name list for its gate: its CI has no etch build, and a misspelled action (`zsh.oh_my_zsh`, fixed in etch-config#13) aborted every full apply from 2026-06-10 to 2026-10-25. |
