# CLI

## Basic usage on local manifests

etch works by running a manifest or set of manifests. Following are examples of running etch against manifests that are on the local machine:

```shell
# Run all manifests within your current directory
etch apply

# Run all manifests within your current directory and a specified configuration file
etch -d ./ -c /path/to/etch.yaml

# --manifests, or -m, will run a subset of your manifests
etch -d ./ apply -m one,two,three

# Run all manifests within a specified directory
etch -d ./manifests apply
```

Please refer to the [commands](commands.md) section for more information about the usage of `apply`.

## Basic usage on remote manifests

etch also has the ability to run remote manifests, normally hosted in a git repository on github.

```shell
# Manifests in a Git repository
etch -d https://github.com/brujack/etch-cli apply

# Manifests in a Git repository with a branch and path
etch -d https://github.com/brujack/etch-cli#main:dotfiles apply

# Manifests in a Git repository with a branch and path and a subset selector
etch -d https://github.com/brujack/etch-cli#main:dotfiles apply -m dev.git
```

## Help menu

etch provides a help menu that can be shown by running the following command in your terminal:

```shell
etch -h
```

## Auto generate completions

Shell completions for etch can be generated by the desired shell via `gen-completions` subcommand.

```shell
etch gen-completions [SHELL]
```

for bash:

```shell
source <(etch gen-completions bash)
```

for fish:

```shell
etch gen-completions fish | source
```

## Define variables via CLI

etch offers the ability to set variables to use throughout manifests. Variables have normally been defined via the etch config file named `etch.yaml` at the root directory of the manifests. However, variables can also be defined in the command line interface by using the `defines` options.

```shell
etch -v -d ./ --defines foo=bar apply -m sample
```

In the sample, a variable is created in etch with the name `foo` and is set to the value `bar`. An action, like the sample below, can utilize this variable.

```yaml
- action: command.run
  command: echo
  args:
      - "{{ variables.foo }}"
```
